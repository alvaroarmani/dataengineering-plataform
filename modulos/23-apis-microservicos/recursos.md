# Recursos — Módulo 23 (APIs, Microserviços e Integração)

## Livros
- **Kleppmann, M. — Designing Data-Intensive Applications** (2017): **cap. 4** (encoding/dataflow,
  REST/RPC, mensageria) e **cap. 9/11** (consistência, idempotência, eventos). Âncora do módulo.
- **Reis, J.; Housley, M. — Fundamentals of Data Engineering** (2022): ingestão via APIs/eventos,
  idempotência e observabilidade como *undercurrents*.
- **Densmore, J. — Data Pipelines Pocket Reference** (2021): padrões de ingestão de APIs e brokers.
