# Módulo 15 — Carreira, Portfólio e Preparação para Entrevistas

> Traduzir competência em oferta de emprego: portfólio, currículo e processo seletivo.

## Identificação
- **Eixo:** 5 — Carreira e Integração
- **Carga horária:** 20h
- **Pré-requisitos:** Eixos 1–4
- **Onde roda:** GitHub + prática de entrevista

## Ementa
Construção de portfólio no GitHub (READMEs que vendem, projetos que rodam). Currículo e
LinkedIn para dados (formato Situação → Ação → Resultado). Preparação técnica: SQL ao vivo
(live coding), case de modelagem dimensional, system design de pipeline de dados, perguntas
comportamentais. Trilha complementar de certificações (dbt, Astronomer/Airflow, Google Cloud
Professional Data Engineer). Mapa de vagas e como se candidatar.

## Competências e habilidades
- C13 — construir portfólio e conduzir-se em processos seletivos.

## Objetivos de aprendizagem
1. **Organizar** um portfólio GitHub com 3–5 projetos + TCC.
2. **Escrever** currículo/LinkedIn orientados a resultado.
3. **Resolver** SQL ao vivo e conduzir um system design de dados.
4. **Planejar** certificações complementares.

## Plano de aulas (unidades)
1. Portfólio e READMEs que convencem.
2. Currículo e LinkedIn para dados.
3. Entrevistas: SQL ao vivo, modelagem, system design, comportamental.
4. Certificações e estratégia de candidatura.

## Metodologia e avaliação
**Maestria:** portfólio publicado + currículo revisado + um *mock interview* (use a IA como banca).

## O que o mercado espera
Candidatos que **mostram** trabalho (portfólio) e sabem **explicar** decisões passam mais.

## Erros comuns
- Portfólio só com notebooks que não rodam.
- Currículo listando ferramentas sem resultados.
- Não praticar SQL ao vivo antes da entrevista.
