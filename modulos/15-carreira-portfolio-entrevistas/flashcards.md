# Flashcards — Módulo 15

Revisão espaçada. Cubra a resposta, responda de memória, confira.

- **P:** Por que portfólio > currículo para quem migra? / **R:** Prova competência com evidência verificável (código que roda), no lugar da experiência formal.
- **P:** O que um bom README responde? / **R:** O quê, por quê (problema), arquitetura (diagrama), como rodar, o que aprendi.
- **P:** Profundidade ou volume no portfólio? / **R:** Profundidade: 3 projetos completos (testes, docs, CI) contando a história do pipeline inteiro.
- **P:** Como é um bom bullet de currículo? / **R:** O que fez + com que ferramenta + resultado (com número), alinhado às palavras-chave da vaga.
- **P:** Método do SQL ao vivo? / **R:** Esclarecer → planejar → escrever incremental → tratar bordas (NULL/duplicata/empate), pensando em voz alta.
- **P:** Padrões de SQL que caem? / **R:** JOINs, GROUP BY+agregações, window functions, CTEs, tratamento de NULL/duplicata.
- **P:** Os 4 passos de Kimball num case? / **R:** Processo de negócio → grão → dimensões → fatos = star schema.
- **P:** Por que o grão é a decisão-chave? / **R:** Define o que uma linha da fato representa; tudo (dimensões, medidas, detalhe) depende dele.
- **P:** 1º passo do system design de dados? / **R:** Levantar requisitos (volume, latência, consumidores, custo) antes de citar ferramentas.
- **P:** O que decide batch vs streaming? / **R:** A latência: janelas (ex.: horário) → batch (mais simples/barato); segundos → streaming.
- **P:** O que são undercurrents? / **R:** Qualidade, segurança, gestão, DataOps, arquitetura e orquestração que permeiam o pipeline; citá-las mostra maturidade.
- **P:** Certificação substitui portfólio? / **R:** Não; complementa (filtros de RH, estudo, sinalização). Priorize projetos; escolha uma alinhada à vaga.
