## Livros e artigos
- **Beauchemin, M. — The Rise of the Data Engineer** (2017): a disciplina como engenharia de software — o porquê de Git/testes/docs pesarem no portfólio.
- **Reis, J.; Housley, M. — Fundamentals of Data Engineering** (2022): papel, competências e *undercurrents* do engenheiro de dados.
- **Tanimura, C. — SQL for Data Analysis** (2021): window functions e padrões cobrados no SQL ao vivo.
- **Kimball, R.; Ross, M. — The Data Warehouse Toolkit** (2013): o roteiro do case de modelagem dimensional.
- **Kleppmann, M. — Designing Data-Intensive Applications** (2017): vocabulário de system design (confiabilidade/escalabilidade, batch vs stream).
