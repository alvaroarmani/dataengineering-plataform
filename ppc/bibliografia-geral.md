# Bibliografia Geral

Referências centrais que guiam o curso. O detalhamento por tema está nos `recursos.md`
de cada módulo. Preferimos **fontes primárias** (livros de referência, papers seminais e
documentação oficial) a tutoriais efêmeros.

## Livros-âncora

- **Reis, J.; Housley, M.** *Fundamentals of Data Engineering.* O'Reilly, 2022. — Visão moderna e conceitual da área (o "porquê" do ciclo de vida do dado).
- **Kimball, R.; Ross, M.** *The Data Warehouse Toolkit.* 3ª ed., Wiley, 2013. — Bíblia da modelagem dimensional.
- **Kleppmann, M.** *Designing Data-Intensive Applications.* O'Reilly, 2017. — Fundamentos de sistemas de dados (armazenamento, replicação, batch/stream).
- **Densmore, J.** *Data Pipelines Pocket Reference.* O'Reilly, 2021. — Padrões práticos de pipelines (ETL/ELT).
- **McKinney, W.** *Python for Data Analysis.* 3ª ed., O'Reilly, 2022. — pandas pelo criador.
- **Ramalho, L.** *Fluent Python.* 2ª ed., O'Reilly, 2022. — Python idiomático e avançado.
- **Tanimura, C.** *SQL for Data Analysis.* O'Reilly, 2021. — SQL analítico aplicado.

## Papers e artigos seminais

- Dean, J.; Ghemawat, S. *MapReduce: Simplified Data Processing on Large Clusters* (2004).
- Armbrust, M. et al. *Delta Lake: High-Performance ACID Table Storage* (VLDB, 2020).
- Dehghani, Z. *Data Mesh Principles* (martinfowler.com).
- Kreps, J. *The Log: What every software engineer should know about real-time data's unifying abstraction*.
