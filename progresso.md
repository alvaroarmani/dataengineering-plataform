# Progresso

Tracker de maestria. Marque cada módulo só quando cumprir o **critério de conclusão**
(`pytest` verde + quiz ≥ 80% + projeto conforme rubrica). O [Dashboard](dashboard.md) lê o
[`progresso.json`](progresso.json) e reflete isto visualmente.

## Como usar

- `[ ]` não iniciado · `[~]` em andamento · `[x]` concluído por maestria.
- Ao concluir, atualize também o `progresso.json` (o dashboard usa esse arquivo).
