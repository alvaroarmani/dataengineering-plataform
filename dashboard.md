# Dashboard

Seu painel de progresso. O estado (streak, módulos concluídos) é salvo **no seu navegador**
(`localStorage`) — clique nos módulos para marcá-los. Para versionar seu avanço
(build-in-public), atualize também o [`progresso.json`](progresso.json).

```{raw} html
<div id="mapa-curso">
  <p><em>Carregando seu progresso…</em> Se nada aparecer, seu navegador pode estar com JavaScript desativado — o conteúdo do curso funciona normalmente sem o dashboard.</p>
</div>
```

:::{admonition} Como o streak funciona
:class: tip
Cada dia que você abre o curso conta +1 no streak. Pulou um dia? Ele reinicia. O
**modo 5-min hoje** (revisar 5 flashcards de um módulo já concluído) é suficiente para
manter a sequência num dia corrido.
:::
